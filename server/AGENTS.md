# 飞书多维表格抖音爆款视频筛选流程

## 目标

从指定的飞书多维表格读取抖音对标账号，筛选近一个月内点赞数严格大于 5000 的视频，核验详情页数据后写入目标数据表。

## 飞书数据源与目标表

### 源表

- 文档：`https://my.feishu.cn/wiki/Jda7wxXXxijx6okIVD1cUkPVn9c?table=tblDskgZg3lZ0Y14&view=vewnuWKzP8`
- 数据表：`对标博主账号信息表`
- Table ID：`tblDskgZg3lZ0Y14`
- View ID：`vewnuWKzP8`
- 必读字段：`博主名称`、`抖音主页链接`

### 目标表

- 文档：`https://my.feishu.cn/base/IOEQbJ9EeaVlLfs9FaicqFFVnhU?table=tblDl0YJgPuQR9Aj&view=vewYMVoCPR`
- 数据表：`对标账号爆款`
- Table ID：`tblDl0YJgPuQR9Aj`
- View ID：`vewYMVoCPR`
- 写入字段与顺序：`视频发布时间`、`账号`、`点赞数`、`收藏数`、`视频链接`
- `状态`字段始终留空，由用户后续手动更新。

> 写入前必须同时校验数据表名称和 Table ID。不得写入同一个 Base 中的 `爆款文案改写记录`或其他数据表。

## 筛选口径

1. 时区固定为 `Asia/Shanghai`。
2. 每次运行时重新计算时间下限，默认为执行日往前一个自然月的 `00:00:00`；边界时间包含在内。如用户指定了明确起始日期，以用户指定值为准。
3. 点赞数必须严格大于 `5000`；`5000` 不合格。
4. 页面展示的 `1.2万` 等数值需归一化为整数，例如 `1.2万 -> 12000`。
5. 最终判定必须以视频详情页显示的发布时间和点赞数为准，不能只根据主页卡片或视频 ID 估算。

## 处理步骤

1. 读取源表全部记录，提取 `博主名称` 和 `抖音主页链接`。
2. 从带有“长按复制”等文案的单元格中提取真实 URL；将 `v.douyin.com` 短链接还原为最终抖音主页地址。
3. 按还原后的主页 URL 去重。对空值、纯文字、失效链接和无法打开的主页记录原因，不伪造或猜测数据。
4. 扫描每个可访问主页的全部作品，包含置顶作品。不得假设置顶作品的时间顺序，也不得因首屏未显示更多作品就提前结束。
5. 主页阶段可用视频 ID 推导的时间做初筛，但必须在时间下限前额外保留至少 `48 小时`的缓冲窗口，防止 ID 时间与实际发布时间存在偏差。
6. 对初筛视频逐条打开详情页，提取并核验：实际发布时间、点赞数、收藏数、视频链接。
7. 按详情页的实际发布时间和点赞数再次执行最终筛选。
8. 写入前读取目标表已有的 `视频链接`，以视频 ID 或视频链接去重；已存在的视频直接跳过。
9. 在批量写入前汇总“合格数、已存在数、待新增数”，待用户确认后写入目标表。
10. 只新增记录，不修改、覆盖或删除既有记录。

## 字段映射

| 目标字段 | 数据来源 | 写入规则 |
| --- | --- | --- |
| `视频发布时间` | 抖音视频详情页 | 写入详情页日期，格式 `YYYY/MM/DD` |
| `账号` | 源表 `博主名称` | 写入账号名称，不在该字段混入视频链接 |
| `点赞数` | 抖音视频详情页 | 归一化后的整数 |
| `收藏数` | 抖音视频详情页 | 归一化后的整数 |
| `视频链接` | 抖音视频详情页 | 使用 `https://www.douyin.com/video/<video_id>` 的标准链接 |
| `状态` | 无 | 留空 |

## 写入后验收

- 目标表记录数应等于“写入前记录数 + 本次待新增数”。
- 核对新增记录的日期、账号、点赞数、收藏数和视频链接是否落在正确列。
- 确认视频链接可点击，并与候选视频 ID 一致。
- 确认 `状态` 为空，原有记录未被修改。
- 输出处理结果：源表记录数、有效链接数、去重后账号数、合格视频数、跳过重复数、新增数、失败或无效数及原因。
