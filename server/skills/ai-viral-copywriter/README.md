# ai-viral-copywriter

一个面向中文 AI 工具 / 教程 / 工作流内容的短视频爆款文案 Skill。

## 使用方式

把整个 `ai-viral-copywriter` 文件夹放进你的 Skills 目录中即可。

核心文件：

- `SKILL.md`：完整技能规则

## 适合场景

- AI 工具教程
- Codex / Claude Code 教程
- 智能体 / 技能 / 工作流
- 图片生成与编辑
- PPT / 科研 / 办公效率
- 小红书 / 抖音 / 视频号口播文案
- 爆款标题
- 低粉爆款风格改写
- 文案结构拆解
