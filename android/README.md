# 爆款文案助手 Android 客户端

## 功能

- realme / Android 手机上的系统悬浮球。
- 用户主动粘贴抖音或小红书分享链接。
- “提取文案”“改写文案”“保存”三个独立动作。
- 最多同时运行 3 条视频任务；从“后台任务队列”切换回任意视频的提取、改写和保存流程。
- 手机断网或面板关闭后，Mac 任务仍继续处理。
- 原文案和改写稿可编辑；改写稿为空也可保存。

## 首次连接

1. Mac 和手机安装 Tailscale，登录同一账户并连通。Android 同一时间只能启用一个 VPN；使用本助手时需要停止 Clash，再连接 Tailscale。
2. 在 `server` 目录运行：

   ```bash
   node scripts/setup-mobile-access.mjs http://Mac的Tailscale名称:3300
   ```

3. 重新构建并启动 Mac 服务。
4. 安装 APK，打开应用，将 `mobile-connection.txt` 中的电脑地址和访问令牌填入设置。
5. 点击“保存并测试连接”，成功后开启悬浮球。
6. 在 realme 设置中允许“显示在其他应用上层”、通知和后台运行，并将电池策略改为“不限制”。

不要通过路由器映射 3300 端口。手机版接口必须同时依靠 Tailscale 私有网络和应用访问令牌。

## 后台任务队列

1. 粘贴第一条链接并点击“提取文案”。任务开始后，可直接粘贴下一条链接继续提交。
2. 悬浮面板顶部显示“后台任务队列（运行数/3）”。
3. 点击队列中的视频，可切回该视频并继续改写或保存。
4. 关闭面板、切换应用或锁屏不会取消 Mac 上已提交的任务。
5. 三个槽位都在运行时，新视频会提示“后台任务已满”；任一任务结束后即可继续提交。

抖音游客 Cookie 被风控时，Mac 会自动改用本机 Chrome 的抖音登录态通过 yt-dlp 解析。请保持 Chrome 中的抖音登录有效；Cookie 只在 Mac 本机读取。

## 构建

需要 JDK 17 和 Android SDK 35：

```bash
./gradlew assembleDebug
```

输出文件：`app/build/outputs/apk/debug/app-debug.apk`。
